◆ update()

void PhysicsEngine::update ( float dt)

Advances the simulation by one time step dt.

  1. Applies global forces (Gravity downward).
  2. Applies N-body forces (Gravity, Electrostatics).
  3. Integrates motion (Updates positions and velocities).
  4. Detects and resolves collisions (Body-Body, Body-Walls).
    Parameters
    dtDelta time (time step) in seconds.
